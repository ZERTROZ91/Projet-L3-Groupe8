# PASSERELLE – Robot Groupe 8

## Description
Passerelle en bâtonnets de bois conçue pour permettre 
le passage du robot de la rampe à la plateforme de tir.

## Conception
- Structure de type treillis Warren
- 150 bâtonnets de bois (114 × 10 × 2 mm)
- Assemblage par collage
- Dimensions finales : 900 × 300 × 86 mm

## Choix techniques
- Treillis Warren : meilleur compromis rigidité/matière
- Colle préférée aux vis pour répartir les contraintes
- Finition esthétique avec peinture

## Tests et résultats
- Passage du robot validé
- Résistance validée jusqu'à 150 N
- Flèche centrale à 15 N : 0.6 mm
