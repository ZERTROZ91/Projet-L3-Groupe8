# COQUE – Robot Groupe 8

## Description
Coque sur le thème d'un char d'assaut, fabriquée en 3 parties :
- Partie basse : thermoformage PS Choc sur moule MDF
- Tourelle : bois retravaillé à la ponceuse à ruban
- Canon : conçu sous SolidWorks, imprimé en 3D (PLA)

## Supports capteurs
- Capteur ultrasonique : support 3D sur servo-moteur (balayage 180°)
- Capteur couleur + suiveur de ligne : équerre sur beam, vis/écrous

## Contenu du dépôt
- `design_coque/` : photos et réflexions de conception
